# TONFLOW

Мини-приложение: Wallet, P2P, Roulette, Profile. Чистый HTML/CSS/JS, данные в LocalStorage. Баланс виртуальный, реальных переводов нет.

## 1. Настройка (config.js)
- `ADMIN_TG_IDS: [123456789]` — ваш Telegram ID (узнать: бот @userinfobot). Только он увидит админ-панель внутри Telegram.
- `ADMIN_DEMO` — вход по коду вне Telegram, нужен только для проверки в браузере. Перед запуском поставьте `false`.
- Курсы, комиссии, стартовые балансы, аватарки ордеров и шансы рулетки по умолчанию.

## 2. GitHub Pages
1. На github.com: New repository (публичный), загрузите все файлы из этой папки (Add file → Upload files).
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. Через минуту сайт: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`. Должен открываться по https.

## 3. Бот в Telegram
1. @BotFather → `/newbot` → имя и username → получите токен.
2. `/newapp` (или `/mybots` → ваш бот → Bot Settings → Menu Button → Configure) → вставьте ссылку GitHub Pages.
3. Откройте бота и нажмите кнопку меню. Приложение откроется внутри Telegram.

## 4. Админ-панель
Админ: 5 быстрых нажатий на логотип TONFLOW (или кнопка «Админ-панель» в профиле). Там создание ордеров (ник, аватар-эмодзи, курс, объём, лимиты, оплата), включение, удаление, статусы сделок и шансы рулетки.

## Ограничения
Все данные хранятся на устройстве пользователя. Проверка админа по Telegram ID выполняется в браузере и не является защитой. Для общего для всех списка ордеров и настоящих прав нужен backend (например, Supabase, см. `SUPABASE` в config.js).
